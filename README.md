## 📌 Project Overview

ShopSphere is a responsive e-commerce web application that allows users to browse products, search and filter products by category, add products to a shopping cart, manage quantities, remove products, and complete a simulated checkout.

The project demonstrates modular frontend development, client-side functionality, responsive UI design, browser LocalStorage, GitHub version control, and live deployment using Render.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🛍️ Product Catalog
- 🔎 Product Search
- 📂 Category Filtering
- 🛒 Add to Cart
- ➕ Increase Product Quantity
- ➖ Decrease Product Quantity
- ❌ Remove Products
- 🗑️ Clear Cart
- 💾 LocalStorage Cart Persistence
- 💰 Automatic Total Price Calculation
- 📦 Simulated Checkout
- 📱 Responsive Mobile Design
- ☰ Mobile Navigation Menu
- ℹ️ About Page
- 🚀 Live Deployment on Render
